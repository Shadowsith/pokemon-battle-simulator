Lege hier deine eigenen Move-Sounddateien ab, benannt nach der `soundId`
aus src/app/core/models/move.model.ts, z.B.:

  assets/sounds/tackle.mp3
  assets/sounds/energy_ball.mp3
  assets/sounds/thunderbolt.mp3

Pokémon-Cries (optional, für Einwechseln/Sieg) unter:

  assets/sounds/cries/{dexId}.mp3
